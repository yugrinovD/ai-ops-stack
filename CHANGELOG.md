# Changelog

All notable changes to this project are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project follows [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-21

### Added

- Shared Compose stack for `gogate`, `lmlog`, `ops-console` and Ollama.
- Generated local secrets and gateway key bootstrap.
- `make smoke` and `make smoke-fallback` end-to-end checks.
- Browser-facing Jaeger links, Prometheus/Grafana and OTLP tracing.
- Resource ownership documentation for `gogate`, `lmlog`, `ops-console`,
  `ledger` and Ollama.
- Sanitized demo screenshots and recording plan.
